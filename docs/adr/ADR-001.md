# ADR-001: Password hashing algorithm

Status: Accepted

Context

We need a secure, well-supported password hashing algorithm for v1 of the login system.

Decision

Use bcrypt with a cost factor of 12 (configurable).

Consequences

- Pros: widely supported, slow hashing reduces brute-force risk.
- Cons: CPU-bound; choose cost carefully for environment.

Notes

Can be replaced by argon2 in future versions if available in deployment environment.
